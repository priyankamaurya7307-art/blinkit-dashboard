# blinkit-dashboard
This project is a Power BI dashboard developed to analyze Blinkit's sales performance, customer behavior, and product insights. The dashboard transforms raw business data into interactive visualizations, enabling data-driven decision-making and performance tracking.
📊 Dashboard Highlights
Total Sales Analysis
Average Sales & Revenue Tracking
Product Category Performance
Outlet Type and Location Analysis
Customer Rating Insights
Item Visibility and Sales Trends
Interactive Filters and Slicers for Dynamic Reporting
🛠️ Tools & Technologies
Power BI Desktop
Power Query
DAX (Data Analysis Expressions)
Data Visualization Techniques
🎯 Project Objective
The objective of this dashboard is to provide a comprehensive view of Blinkit's business performance by analyzing sales, customer ratings, product categories, and outlet characteristics. It helps identify key trends and supports informed business decisions.
📈 Key Insights
Identified top-performing product categories.
Analyzed sales distribution across different outlet types and locations.
Evaluated customer ratings and their impact on sales.
Monitored overall business growth and performance metrics.
